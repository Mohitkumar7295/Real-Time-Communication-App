Architecture & Security

Full Mesh Topology

MeetApp uses pure browser-native WebRTC mesh. Each participant connects directly to every other participant. This eliminates centralized video media servers, lowering latency and infrastructure cost, but creates an upload bandwidth ceiling suitable for up to 5 concurrent participants.

What is Protected & What is Not

  • Media Streams: Fully encrypted in transit via WebRTC DTLS-SRTP. The server never sees raw audio/video.
  • Chat & Files: Encrypted in transit (HTTPS/WSS) and encrypted at rest with AES-256-GCM using authenticated room/file AAD. Because the server decrypts messages for authorized participants, this is not client end-to-end encryption.
  • IP Disclosure: In direct P2P mesh, peers can see each other's IP addresses. Connecting via TURN relays hides client IPs behind the relay address.
